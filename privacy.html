Privacy notice

Last updated 25 October 2026 · Describes the v0.4.7 desktop implementation.

Operator and scope

The operator is Nicola Giovanni Strambio de Castillia, contactable at nic.strambio@gmail.com. This notice describes a personal desktop teaching-timetable assistant. It is not an invitation to connect other people's Google accounts or a description of a public hosted service.

Google data accessed

With the operator's consent, the app obtains the signed-in Gmail address, searches for timetable messages using a configured sender, subject and date window, and reads matching message details, bodies and PDF attachments. The Gmail read permission is broader than this search filter; the filter describes how this version uses that permission.

Calendar access reads the calendar list and event details needed to check schedule overlaps, including titles, dates, times, attendance responses and availability. Calendar writes are restricted by the requested permission to calendars created by this app. The application uses its ownership markers to update or remove its managed lessons in the dedicated work calendar.

Gmail send access is used to send summaries to the authenticated account itself. Reports may include teaching details, source-message text, calendar names, overlapping event titles and diagnostic information. Google data is used for these timetable functions, not sold, used for advertising or used by this application to train general-purpose AI models.

Optional image extraction

The operator manually saves a timetable image in an input folder. The app sends that image, the target teacher's name and the reference week to Google's Gemini API, which returns structured schedule data. The app does not access WhatsApp messages or contacts directly. In this implementation, Gmail PDF extraction happens locally; Gmail messages, their PDF attachments and calendar-conflict details are not sent to Gemini.

Gemini's processing, retention and data-use conditions depend on the applicable service terms, region and project configuration. Review the Gemini API terms for the account in use. Local deletion does not itself delete provider logs. The operator must ensure that submitted images are appropriate for this processing and that processing is permitted.

Where information is stored

Google stores the original email, calendar events and emailed reports in the relevant account. The desktop app keeps extraction JSON, image caches, archived images, reports and synchronization state in its configured local folders. PDF attachment bytes are processed in a temporary directory that is removed on normal completion. Derived lesson details and source information can remain in reports and events.

Google refresh credentials and a saved Gemini key use the operating system's credential store in the protected-storage setup. Desktop OAuth configuration remains in credentials.json; an environment-variable Gemini key is also supported. App data and reports are not encrypted by the application. Folders placed under OneDrive or another synchronization service can also be copied to that service and other linked devices.

Sharing and retention

The configured service providers process the data necessary for their functions. There is no separate developer-operated server in this desktop version. The program adds no advertising or analytics service. Access by people with permission to the operator's Google calendars, email, device or synchronized folders is governed by those existing permissions.

There is no automatic age-based deletion of weekly records, cached images, reports or calendar events. They remain until the operator deletes them or the relevant provider applies its own retention settings. Deleting a local file does not remove Google Calendar events, Gmail reports, cloud copies or backups.

Stopping access and deleting data

The operator can disable the Windows scheduled task, stop running the program, and revoke its Google access in Google Account connections. Revocation prevents future authorized requests but does not erase existing information. The operator can separately delete managed calendar events, emailed reports, local caches and records, synchronized copies and stored credentials. Remove or revoke the Gemini key to stop its further use.

This information website

The supplied pages contain no analytics, login forms, upload forms, cookies set by site code, or external scripts. These information pages are intended for hosting on GitHub Pages. GitHub logs and stores visitor IP addresses for security purposes under the GitHub Privacy Statement. The information website does not receive Gmail messages, timetable images, calendar data or the desktop installation's credentials.

Google API data-use commitment

Google API data is used only to deliver the described timetable features. Any use or transfer must follow the Google API Services User Data Policy, including its Limited Use requirements.

Updates and enquiries

Send questions or deletion requests concerning information held by the operator to nic.strambio@gmail.com. Update this notice and obtain any necessary consent before changing data uses, introducing a hosted backend, connecting new users or adding new service providers.
